## 📋 Overview 📖
**CODEPLAY** is a lightweight and interactive **live code editor** that allows users to write **HTML, CSS, and JavaScript** and instantly see the output in the browser.  

💡 Inspired by **VS Code layout**, it provides a simplified coding environment for learning and experimentation.

---

## ✨ Features 🌟

- 🧑‍💻 Live HTML, CSS & JavaScript editing  
- ⚡ Real-time output preview  
- 🖥️ VS Code–style editor layout  
- 🎨 Clean and minimal UI  
- 🟢 Beginner-friendly  
- 🌐 Runs directly in the browser  

---

## ⚠️ Limitations 🚧

- 📱 Not optimized for mobile devices  
- 💻 Best experience on desktop/laptop  

---

## 🛠️ Tech Stack ⚙️

- 🧱 HTML  
- 🎨 CSS  
- ⚡ JavaScript
