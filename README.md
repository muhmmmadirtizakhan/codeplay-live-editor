#▶️ CODEPLAY – Live Code Editor

**CODEPLAY** is a lightweight **live HTML, CSS, and JavaScript code editor** inspired by the workflow and layout of **VS Code**.  
It allows developers to write code and see the output instantly in the browser.

This project is built using **pure frontend technologies** and focuses on simplicity, performance, and learning.

---

## 🚀 Features

- 🧑‍💻 Live **HTML, CSS & JavaScript** editing
- ⚡ Real-time output preview
- 🖥️ VS Code–style editor layout
- 🎨 Clean, minimal user interface
- 🟢 Beginner-friendly and fast
- 🌐 Runs directly in the browser

---

## 🛠️ Tech Stack

- **HTML**
- **CSS**
- **JavaScript 

---

## 🎯 Project Purpose

The purpose of **CODEPLAY** is to:

- Understand how live code editors work
- Practice frontend development concepts
- Build a VS Code–like coding experience using JavaScript
- Showcase practical skills in a frontend portfolio

This project is suitable for **students, beginners, and frontend learners**.
